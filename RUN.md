# Running Sigil

> Section 1 is the list of steps only a human can do; everything else is scripted. Sections 2 onward are the commands that exist in the repo today, the demo sequence with the log lines you should see, the env vars each package reads, and what to do when something fails.

## 0. Toolchain

```bash
export PATH="$HOME/Library/pnpm:$HOME/.nvm/versions/node/v22.13.0/bin:$HOME/.foundry/bin:$PATH"   # pnpm 11.5 (npm -g on macOS lands in ~/Library/pnpm), Node 22.13 (node, npm, corepack) and the circle CLI, forge 1.5
npm i -g pnpm@11.5.0   # or `corepack enable`, which honours `packageManager` in package.json; the Node bin dir does not ship pnpm
pnpm install
cp .env.example .env   # then fill the keys below
```

`which -a pnpm` should list the 11.5.0 you just installed first; a stale corepack shim from an older nvm Node fails with `Cannot find matching keyid` while trying to fetch 11.5.0. pnpm 11.5 itself refuses to run on Node < 22.13 (`ERROR: This version of pnpm requires at least Node.js v22.13`; the root `engines` field matches but only warns, there is no `.npmrc` with `engine-strict`). `forge` is only needed for `pnpm test` (contracts) and `pnpm deploy`.
